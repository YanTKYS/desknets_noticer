# インストール手順

## 1. パッケージ化されていない拡張機能として読み込む

この拡張機能はビルド不要です。Node.jsやnpmが無い環境でも、そのままChromeに
読み込めます（テストの実行にのみNode.jsを使用しますが、拡張機能の動作には不要です）。

1. Google Chromeで `chrome://extensions` を開く。
2. 右上の「デベロッパー モード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックする。
4. このリポジトリの `desknets_noticer` フォルダ（`manifest.json` が直接置かれている
   フォルダ）を選択する。`src` フォルダなど、内側のフォルダを選ばないよう注意する。
5. 拡張機能一覧に「desknet's noticer」が表示され、ツールバーにアイコンが表示されることを
   確認する。読み込み時にManifestエラーが表示されないことも確認する。

## 2. desknet's NEOへログインする

拡張機能はID・パスワードを保存しません。Chromeで通常どおりdesknet's NEOにログインした
状態（ログイン済みセッション）を利用します。

## 3. 拡張機能の設定を行う

1. ツールバーのアイコンをクリックし、ポップアップから「設定」を開く。
   または `chrome://extensions` の拡張機能詳細から「拡張機能のオプション」を開く。
2. 「接続先」欄に、**電子会議室の「新着情報」画面を開いた状態のURL**を入力する。
   - desknet's NEOのトップ画面URLやログイン後のポータルURLではなく、電子会議室の
     新着情報一覧が表示されている画面のURLを、ブラウザのアドレスバーからコピーして
     使用すること。
3. 「接続確認」ボタンを押し、正しく接続できるか確認する。
   - 初回はアクセス許可を求めるダイアログが表示されるため、許可する。
4. 「通知対象トピック」で、通知対象1・通知対象2それぞれについて設定する。
   - 「トピック名」欄には、自組織の電子会議室で実際に使われているトピック名を
     過不足なく入力する（完全一致で判定されるため、表記が少しでも異なると
     一致しない）。
   - 初期値は「公用車キャンセル周知用」「会議室キャンセル周知用」だが、実際の
     名称と異なる場合は書き換えること。
   - 通知を受け取りたい対象だけ「通知する」にチェックを入れる。
   - **初期状態ではどちらも「通知する」がOFFです。**
5. 「確認間隔」（3分・5分・10分）を選択する。初期値は5分。
6. 「通知設定」でデスクトップ通知や本文表示の有無を設定する。
   - Windows側で通知が表示されるかどうかだけを先に確認したい場合は、
     「テスト通知を表示」ボタンを押す（desknet's NEOへはアクセスしません）。
7. 「設定を保存」を押す。保存時に、入力したURLへのアクセス許可を求めるダイアログが
   表示された場合は許可する（このオリジンのみへのアクセス許可であり、他のサイトへは
   アクセスしない）。

## 4. 動作確認

1. 「接続確認」を押し、「認識した投稿件数」が0件以外になることを確認する。
   0件のままの場合は、接続先URLが本当に「新着情報」画面を指しているか、
   desknet's NEOの画面が変更されていないかを確認する。
2. ポップアップを開き、「今すぐ確認」を押す。
3. 設定画面に戻り、有効にしたトピックが「初回確認: 完了」になっていることを確認する
   （この時点では通知されない）。
4. desknet's NEO側で、対象トピックへ実際にテスト投稿を行う。
5. 再度ポップアップを開き「今すぐ確認」を押す。テスト投稿についてデスクトップ通知が
   表示されることを確認する。
6. もう一度「今すぐ確認」を押し、同じ投稿が再通知されないことを確認する。
7. 通知をクリックし、電子会議室の新着情報画面が開くことを確認する。
8. ポップアップの「電子会議室を開く」を押し、既存タブがある場合はそのタブが
   新着情報画面へ切り替わることを確認する。

拡張機能を更新した直後は、DOM解析の方式が変わったことで新着判定の基準がリセットされる
場合があります。既存投稿が意図せず通知されるようであれば、設定画面の
「初回確認状態に戻す」を実行してから「今すぐ確認」をやり直してください。

## アンインストール

`chrome://extensions` の拡張機能詳細から「削除」を選択してください。削除すると、
`chrome.storage.local` に保存されていた設定・通知済み履歴もすべて削除されます。
