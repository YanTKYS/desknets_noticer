# インストール手順

## 1. パッケージ化されていない拡張機能として読み込む

1. Google Chromeで `chrome://extensions` を開く。
2. 右上の「デベロッパー モード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックする。
4. このリポジトリの `desknets_noticer` フォルダ（`manifest.json` があるフォルダ）を選択する。
5. 拡張機能一覧に「desknet's noticer」が表示され、ツールバーにアイコンが表示されることを確認する。

## 2. desknet's NEOへログインする

拡張機能はID・パスワードを保存しません。Chromeで通常どおりdesknet's NEOにログインした
状態（ログイン済みセッション）を利用します。

## 3. 拡張機能の設定を行う

1. ツールバーのアイコンをクリックし、ポップアップから「設定」を開く。
   または `chrome://extensions` の拡張機能詳細から「拡張機能のオプション」を開く。
2. 「接続先」欄に、庁内のdesknet's NEOの新着情報画面URL（またはベースURL）を入力する。
3. 「接続確認」ボタンを押し、正しく接続できるか確認する。
4. 保存時に、入力したURLへのアクセス許可を求めるダイアログが表示された場合は許可する
   （このオリジンのみへのアクセス許可であり、他のサイトへはアクセスしない）。
5. 「通知対象トピック」で、通知を受け取りたいトピックにチェックを入れる。
   - 初期状態ではすべてOFFです。希望するトピックだけを有効にしてください。
6. 「確認間隔」（3分・5分・10分）を選択する。初期値は5分です。
7. 「通知設定」でデスクトップ通知や本文表示の有無を設定する。
8. 「設定を保存」を押す。

## 4. 動作確認

1. ポップアップを開き、「今すぐ確認」を押す。
2. 初回確認では、既存の投稿は通知されません（基準値として登録されるのみです）。
3. 新しい投稿がトピックに追加された後、次回の定期確認または「今すぐ確認」で
   デスクトップ通知が表示されることを確認する。

## アンインストール

`chrome://extensions` の拡張機能詳細から「削除」を選択してください。削除すると、
`chrome.storage.local` に保存されていた設定・通知済み履歴もすべて削除されます。
