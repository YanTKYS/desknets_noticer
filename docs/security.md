# セキュリティおよびプライバシー方針

## 基本方針

- 外部サーバー・外部API・CDN・外部ライブラリを一切使用しません。
- desknet's NEOのID・パスワードを保存しません（拡張機能に入力させることもありません）。
- Cookieを独自に読み出して保存することはありません。ブラウザに保持されている
  ログイン済みセッションを、通常の `fetch` リクエストの一部として利用するのみです。
- desknet's NEOに対する投稿・既読化・更新・削除など、状態を変更するリクエストは
  一切行いません（GETによる新着情報画面の取得のみ）。
- CSRFトークンの取得や、それを用いた更新処理は行いません。
- `eval` や動的コード実行、外部スクリプトの読み込みは行いません。
- 取得したHTMLをポップアップ・設定画面へ表示する際は、`innerHTML` ではなく
  `textContent` を使用します（DOM解析結果の組み立ても `textContent` ベースです）。
- 通知クリックで開くURLは、設定済みのdesknet's NEOのオリジンと同一かどうかを
  必ず検証してから開きます。
- 設定画面の「テスト通知を送信」は `chrome.notifications.create()` のみを呼び出し、
  desknet's NEOへは一切アクセスしません（端末の通知機能そのものの切り分け用）。
  通知の作成要求に成功したかどうかまでしか判定できず、実際にWindowsのバナーへ
  表示されたかどうかまでは判定できません。

## 権限とその理由

| 権限 | 理由 |
| --- | --- |
| `storage` | 設定・通知済み履歴・状態を `chrome.storage.local` に保存するため |
| `alarms` | 数分間隔での定期確認をスケジュールするため |
| `notifications` | デスクトップ通知を表示するため |
| `offscreen` | サービスワーカーにはDOM APIが無いため、取得したHTMLをDOM解析する隠しページを作るため |
| `tabs` | 通知クリック時・「電子会議室を開く」時に、既存タブを探してアクティブにするため |
| `optional_host_permissions`（`http://*/*`, `https://*/*` を宣言し、実際には利用者が設定した1オリジンのみを実行時に要求） | Manifest V3では「利用者が後から入力する任意のURL」を静的にホスト権限として宣言できないため、`optional_host_permissions` に広いパターンを宣言した上で、設定保存時に `chrome.permissions.request` でその時点のURLのオリジン1件のみを要求する構成としています。拡張機能が実際にアクセスするのは、利用者が設定したdesknet's NEOのオリジンのみです。 |

`host_permissions`（起動時に自動付与される権限）は空にしており、利用者が設定した
接続先に対する権限は、設定保存時に個別に要求・許可される仕組みです。

## 保存する情報（`chrome.storage.local` のみ、Chrome同期は使用しません）

- 接続先URL、確認間隔、通知対象トピック（内部設定ID・トピック名・トピックURL・
  会議室ID/トピックID・ON/OFF・初回確認状態、最大20件）、通知設定などの設定値
- 通知済み投稿の識別キー（投稿ID由来の文字列、または投稿情報のSHA-256ハッシュ値）
  - 投稿本文そのものは保存しません。識別キーの生成に使った後は保持しません。
- 最終確認日時、前回確認結果、デバッグ情報（件数・エラーコードなど）

## 保存しない情報

- desknet's NEOのID・パスワード
- Cookie
- 投稿本文の全文
- 職員名を含む恒常的なログ

## デバッグ情報についての注意

設定画面の「詳細情報」には、件数やエラーコードなど機械的な情報のみを表示します。
投稿本文・職員名・Cookie・認証情報は、デバッグ情報にもログにも出力しません。
